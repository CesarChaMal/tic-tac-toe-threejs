# Tic-Tac-Toe 3D

A two-player Tic-Tac-Toe game with a 3D board rendered by Three.js and a React interface.

## Requirements

- Node.js 20 or later
- npm
- A browser with WebGL enabled

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Play

- Click or tap an empty tile to place the current player's mark.
- Player X goes first. The game announces a win or a draw and highlights a winning line.
- Select **New game** to reset the board.
- For keyboard play, focus the board and use **1–9** (top-left to bottom-right), the arrow keys, and **Enter**.

## Production build

```bash
npm run build
npm run preview
```
